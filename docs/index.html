itc-statistics-scrapper

SDK телеметрии для ITC Dashboard — Node.js и браузер

Подключается к Express/Next.js или в любой HTML-сайт через <script>. Heartbeat, метрики и инциденты уходят в панель мониторинга ИТС.

Для чего

Телеметрия без лишнего шума

itc-statistics-scrapper — лёгкий клиент без внешних зависимостей. Работает на сервере и в браузере: любой сайт становится видимым для ITC Dashboard.

Раз в заданный интервал SDK отправляет телеметрию на /api/monitoring/telemetry. Если сигнал пропал — статус проекта меняется. Ошибки JS на клиенте или на сервере можно слать как инциденты автоматически.

Что собирает

Один middleware и фоновый heartbeat — и на дашборде появляются метрики, которые нужны для мониторинга сервисов ИТС.

CPU & RAM

Загрузка ядер и память хоста — видно, когда сервис начинает работать тяжелее обычного.

Heartbeat

Регулярный сбор данных о доступности. Нет тика — статус на панели уходит в сбой.

RPS & latency

Запросы в секунду, среднее и p95 времени ответа между тиками.

HTTP-коды

Распределение 2xx / 3xx / 4xx / 5xx — рост ошибок виден без копания в логах.

Посетители

Уникальные IP и суточные визиты — базовая картина трафика сервиса.

Инциденты

Автоперехват uncaughtException / unhandledRejection и ручной reportIncident.

Быстрый старт

Вставьте скрипт и сайт сразу начнет мониториться

Для любого HTML-сайта достаточно CDN. Для Express / Next.js — npm и middleware. Передайте projectId и адрес ITC Dashboard.

В браузере дашборд должен разрешать CORS на POST /api/monitoring/telemetry.
